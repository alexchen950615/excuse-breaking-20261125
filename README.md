One funny line an AI agent says to its human right after breaking production,
written to `/output/entry.txt` by `main.py` for the
[make.fun competition](https://make.fun/c/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66).

## Run

```sh
python3 main.py
```

The entry is written to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
